## ✨ Features that Slap

*   **🔥 Instant Preview**: Type on the left, see slides on the right. Zero latency.

*   **📱 Responsive**: Works on your laptop, your tablet, your fridge (probably).

## 🚀 Get Started Locally

Want to hack on it? Let's go!

1.  **Clone the repo:**
    ```bash
    git clone https://github.com/ody9s5eus/instant-markdown-to-slides.git
    cd instant-markdown-to-slides
    ```

2.  **Install dependencies (pnpm is the way):**
    ```bash
    pnpm install
    ```

3.  **Ignite the dev server:**
    ```bash
    pnpm dev
    ```

4.  **Open your browser** and start creating!
